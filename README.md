# 青禾学习空间

校园生活工作台与英语四级学习应用，GitHub Pages 公开课程演示版，由 Codex 根据两份课程实践模板独立实现。

## 功能

- 校园：课表、单双周、教学周与上课提醒、地点示意图、社交日程、模拟成绩加权绩点、规则导入、快递取件、备份恢复。
- 英语：36 个起步词汇、自定义词库、复习计划、3 篇原创阅读、2 段合成语音听力、15 道题、错题订正、写作翻译草稿、倒计时与每日打卡。

## 保存数据

数据保存在当前浏览器，刷新后仍保留。校园与英语数据分别保存，以网站部署路径区分存储空间。没有登录或跨设备云同步。换设备、清理浏览器数据前，请分别导出 JSON 备份，在另一设备导入。

仓库和部署文件仅包含虚构示例。个人记录不会上传到仓库、服务器或模型。课程演示请使用模拟成绩。

## 本地运行

使用 Node.js 22.13 或更新版本：

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

校园入口 `/`，英语入口 `/english/`。静态构建输出在 `dist/`。

## GitHub Pages

在仓库 Settings → Pages → Source 选择 GitHub Actions。推送到 main 后，附带工作流自动测试、构建、发布，并按仓库名设置部署子路径。无需上传 node_modules 或个人运行数据。

自定义域名使用根路径时，将工作流的 GITHUB_PAGES_BASE 调整为 `/`。

## 使用边界

校园地点为示意数据，不提供 GPS 或实时路线；学校开放时间和绩点规则需核实。提醒仅在网页开启时工作。英语内容是原创教学练习，不是历年真题；听力依赖设备英文语音合成。写作保存草稿和提供自查建议，不自动评分。初次访问需要网络，未实现离线缓存。
