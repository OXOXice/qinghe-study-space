# AI 应用实践项目说明

## 项目概述

青禾学习空间包含两个独立入口的网页应用，分别围绕大学生的校园生活管理和英语四级备考展开。它们作为课程实践演示发布在 GitHub Pages，使用同一套界面组件与本地保存机制，学习记录彼此独立。

| 项目 | 体验入口 | 解决的问题 |
| --- | --- | --- |
| 校园生活工作台 | [在线打开](https://oxoxice.github.io/qinghe-study-space/) | 将课程、活动、地点、模拟成绩和取件事项集中管理 |
| 英语四级学习空间 | [在线打开](https://oxoxice.github.io/qinghe-study-space/english/) | 将词汇、练习、错题和每日学习进度集中记录 |

## 项目一：校园生活工作台

### 目标与功能

面向需要安排日常学习与生活的学生，以课表和今日事项为起点，提供以下功能：

- **课程安排**：新增和编辑课程，设置星期、时间、起止教学周及单双周，查看课程状态。
- **校园地点**：分类查看示例地点、开放时间、步行参考信息与示意位置。
- **日程活动**：记录活动时间、地点、参与人和完成状态。
- **模拟成绩**：录入课程分数和学分，按可调整的换算规则计算加权平均分及绩点。
- **快递事项**：保存示例取件信息，区分待取与已取。
- **备份恢复**：导出校园数据为 JSON，校验后恢复备份。

### 建议演示步骤

1. 打开校园应用，浏览今日课程与生活事项。
2. 新增一门课程，设置教学周和单双周，刷新确认保存。
3. 在模拟成绩中修改课程分数，查看加权结果变化。
4. 添加日程或取件事项，完成后更新状态。
5. 导出备份，再通过导入功能恢复记录。

校园地点和初始记录均为虚构示例。课程提醒在网页打开时提供状态提示；绩点结果取决于配置的规则，演示请使用模拟成绩。

## 项目二：英语四级学习空间

### 目标与功能

面向希望形成持续学习习惯的学生，以每日词汇复习、基础练习和学习记录为主：

- **词汇学习**：内置 36 个起步词汇，支持自定义词库、掌握程度和后续复习安排。
- **阅读训练**：提供 3 篇原创基础阅读，提交答案后显示解析。
- **听力训练**：提供 2 段依赖设备语音合成的英文听力材料；阅读与听力共 15 道题。
- **错题订正**：记录错误选项、题目日期和订正状态。
- **写作翻译**：保存练习草稿，提供自查建议。
- **学习计划**：设置目标日期和每日目标，查看倒计时、打卡与连续学习天数。
- **备份恢复**：导出或导入英语学习记录，与校园应用分别保存。

### 建议演示步骤

1. 打开英语应用，设置每日目标与目标日期。
2. 学习一组词汇，记录掌握程度。
3. 完成一篇阅读或一段听力，查看解析和错题。
4. 保存写作草稿并完成当日打卡，刷新确认记录保留。
5. 导出学习备份，再通过导入恢复功能验证记录。

练习内容为原创教学示例，并非历年四级真题或完整备考题库。听力需要浏览器及设备提供英文语音；写作功能保存草稿和自查提示，不提供模型评分。

## 技术实现

| 部分 | 方案 |
| --- | --- |
| 界面 | React 19、TypeScript、Tailwind CSS 4、Lucide 图标 |
| 构建 | Vite 8，多页面入口，支持 GitHub 仓库子路径 |
| 数据校验 | Zod，校验表单和备份的数据格式 |
| 保存 | 浏览器 localStorage，按应用和部署路径区分记录 |
| 保存冲突 | 保存前检查数据修订版本；浏览器支持时使用 Web Locks 协调写入 |
| 错误处理 | 保存失败时提示原因并保留表单，避免显示已保存而实际未保存 |
| 备份 | JSON 导入导出，恢复前校验并确认 |
| 发布 | GitHub Actions 测试、构建，再部署 GitHub Pages |

本仓库是适合静态托管的演示版本，不依赖后端服务器、登录系统或数据库。换浏览器、换设备或清理浏览器数据前，需要分别导出两个应用的备份。

## AI 参与方式

项目以课程要求为起点，使用 OpenAI Codex 进行需求整理、界面方案设计、代码编写、问题修复、测试编写、发布检查和文档整理。项目所有者 OXOXice 提供需求、使用偏好与部署授权，并决定交付范围。

AI 的作用发生在开发过程中。部署后的网页运行不需要 DeepSeek、OpenAI 或其他模型的 API Key；用户在应用中填写的课程、成绩和学习记录由浏览器保存，不发送给模型。

这份说明如实记录 AI 参与情况。课程报告中的个人体验、学习收获和教师验收结论，应由提交者结合实际使用补充。

## 已完成验证

发布前已通过以下检查：

- **6 组核心逻辑测试**：加权绩点、教学周与单双周、课程提醒边界、输入校验、连续打卡、题目与答案数据一致性。
- **39 项浏览器检查**：两个应用的入口与跳转、刷新保存、备份导入导出、移动端布局、数据分离、过期页面保存冲突、存储失败提示及表单保留等。
- **GitHub Actions 验证**：在 Linux 环境安装锁定依赖，执行核心测试、TypeScript 检查和生产构建，完成 Pages 部署。

本地核心测试命令为 `npm test`，生产构建命令为 `npm run build`。39 项浏览器检查是本次发布前的本地验证，未配置为仓库中的自动浏览器工作流。

## 使用限制与后续方向

当前版本需要联网首次访问，未提供离线缓存。它不包含跨设备同步、实时校园导航、真实学校数据接入或 AI 作文评分。后续可在明确数据来源、使用需求和权限范围后，扩充词库与题目、增加离线支持或设计可选的同步服务。
